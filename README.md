## 📋 Project Overview

A comprehensive data analytics and machine learning project analysing **global AI adoption and investment across industries** using real, publicly documented datasets from the **Stanford AI Index** and **McKinsey Global AI Survey**, published via **Our World in Data (OWID)**.

The project covers:
- AI investment by sector and region (2017–2023)
- AI adoption rates by world region (McKinsey survey, 2021–2023)
- AI job postings as a proxy for AI talent demand (14 OECD countries, 2014–2023)
- Supervised ML classification of investment tier (Low/Medium/High) from genuine predictors

---

## 🔍 Problem Statement

Understanding how AI investment flows across industries and geographies — and which sectors attract the most funding — is critical for policymakers, investors, and business leaders. This project analyses publicly available, authoritative data to identify patterns in global AI investment and adoption.

---

## 🎯 Objectives

1. Identify which AI sectors receive the most investment globally.
2. Compare AI investment levels across the US, China, and EU+UK.
3. Analyse year-over-year growth in AI investment (2017–2023).
4. Examine McKinsey survey data on AI adoption by world region.
5. Analyse AI job postings trends as a measure of AI demand.
6. Build and evaluate a valid ML model to classify investment tier from real features.

## 🔄 Methodology

```
Real Data Sources (OWID / Stanford AI Index / McKinsey)
        ↓
Data Download (urllib / feather → CSV)
        ↓
Data Loading (src/data_loading.py)
        ↓
Data Cleaning (src/preprocessing.py)
  - Cast types, remove zero/null investments
  - Add sector_label, industry_group
  - Add log_investment_usd, investment_bn
  - Add investment_tier (data-driven tertiles = ML target)
  - Add period labels
        ↓
Exploratory Data Analysis (31 notebook sections)
  - Univariate, Bivariate, Multivariate
  - Geographic analysis (McKinsey regional adoption)
  - Sector heatmaps, investment trends
  - CAGR analysis
  - AI job postings demand
        ↓
Correlation Analysis
        ↓
Machine Learning (sklearn Pipeline, no leakage)
  - Target: investment_tier (Low/Medium/High) — genuine signal
  - Features: sector, country, industry_group, period, year
  - EXCLUDED from features: investment_usd, investment_bn, log_investment_usd
  - ColumnTransformer: OneHotEncoder (cat) + StandardScaler (num)
  - Models: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting
  - Evaluation: Accuracy, Precision, Recall, F1 (macro), 5-fold CV F1
        ↓
Insights & Recommendations
```

## 📈 ML Performance (actual results)

| Model | Accuracy | F1 (macro) | CV F1 (5-fold) |
|---|---|---|---|
| Logistic Regression | 0.6842 | 0.6743 | 0.6677 |
| Decision Tree | 0.6228 | 0.5828 | 0.5893 |
| **Random Forest** | **0.6842** | **0.6830** | **0.6330** |
| Gradient Boosting | 0.6579 | 0.6521 | 0.6689 |

**Best model: Random Forest** — F1 = 0.683, significantly above random baseline (0.333).

This confirms genuine signal: sector, country, and year **do** predict investment tier.

**No data leakage**: `investment_usd`, `investment_bn`, and `log_investment_usd` are excluded from features.

## ⚠️ Limitations

1. **Limited geographic granularity**: Investment data covers only 4 regions (US, China, EU+UK, World aggregate).
2. **McKinsey survey**: Only 3 years and 6 regions; self-reported data with potential response bias.
3. **AI Jobs data**: 14 OECD countries only — does not cover developing economies.
4. **Nominal USD**: Investment figures not inflation-adjusted — may distort year-over-year comparisons.
5. **Investment ≠ adoption**: Investment levels reflect capital flows, not necessarily organisation-level implementation maturity.
6. **Small ML dataset**: 567 observations limits statistical power of ML models.
7. **Correlational only**: All associations are correlational — causal claims are not made.
